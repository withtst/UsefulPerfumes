# Useful Perfumes / 实用香水

Project Zomboid B42 模组：让原版香水与古龙水具有实际效果，并新增六款香水。

## 功能

- 喷洒香水以降低不开心和压力，获得持续 4 游戏小时的香气效果。
- 不同香水具有尸臭减弱、耐力或疲劳消耗降低、睡眠等不同效果。
- 右键合并同款香水，保留空瓶；新增香水支持在物品栏中显示瓶内液面。
- 支持单人游戏及多人游戏的服务端权威处理；可与 ModernStatus [B42] 配合显示香气状态。

## 安装

将本仓库内容放入游戏用户目录下的 `Zomboid/mods/UsefulPerfumes/`，确认该目录中直接包含 `mod.info` 和 `42.21/`，然后在游戏内启用 **Useful Perfumes / 实用香水**。从 GitHub 下载 ZIP 时，解压后可能需要将目录重命名为 `UsefulPerfumes`。

当前版本 0.7.2。模组声明支持 B42.21–42.99；本次控制台验证使用 B42.22.2（revision `3d39148846`）。不同游戏版本及与其他模组的兼容性请以实际测试为准。

0.7.2 按当前原版睡眠公式补齐少眠/嗜睡特质系数，保持安睡花香的睡眠时长目标为原版的 0.7 倍。隔离服务端通过 690 项完整回归和 34 项睡眠组合断言；图标、液面和走路喷洒另有静态/Kahlua 检查。真实客户端移动、菜单、图标渲染、睡眠表现及 MP 同步尚未验证。

## 项目结构

- `42.21/media/lua/`：客户端、服务端及共享逻辑。
- `42.21/media/scripts/`：物品、液体、模型与音效定义。
- `42.21/media/textures/`、`models_x/`、`sound/`：图标、模型及音效资源。
- `tools/`：新增香水液面图生成和静态检查工具。

## 维护液面图

需要 Python 3 和 Pillow。仓库已包含生成结果，普通玩家不需要运行这些命令。

```sh
python -m pip install Pillow
python tools/generate_liquid_levels.py
python tools/verify_liquid_levels.py
```

生成器根据六款基础图标重新生成备用遮罩和液面帧，预览及检查结果保存在已忽略的 `tools/output/`。新增香水的物品栏图标按液量选择液面帧；其他直接使用引擎原生绘制的界面可能显示原生遮罩。

## 验证状态

静态检查和独立 Lua 夹具已覆盖资源、液面帧与绘制分支。最新瓶内液面方案尚未在真实客户端验证；多人同步与其他模组的兼容性也需要实际测试。
